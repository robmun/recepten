# Recepten

Het kookboek van familie Munnichs: een web-app (PWA) met de gedeelde recepten,
foto's, favorieten en boodschappenlijst, bewaard in Firebase.

- De app: <https://robmun.github.io/recepten/>
- Demo met voorbeeldrecepten, zonder login en alleen-lezen: <https://robmun.github.io/recepten/demo/>
- De vorige versie, als terugvaloptie: <https://robmun.github.io/recepten/vorige/>

Hoe de app in elkaar zit, hoe je een nieuwe versie uitbrengt en hoe je test staat in
[`bron/LEESMIJ.md`](bron/LEESMIJ.md).
